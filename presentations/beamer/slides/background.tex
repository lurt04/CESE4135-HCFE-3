\begin{frame}{Data Background: Cognitive Decline in Older Adults}
	\begin{itemize}
		\item Cognitive decline is a growing concern as populations age, increasing the number of older adults living with memory and cognitive impairments.

		\item The Longitudinal Aging Study Amsterdam (LASA) has followed approximately 5,000 adults aged 55+ since 1992, showing that cognitive abilities generally decline with age, although the rate differs between individuals\cite{lasa2025}.
	\end{itemize}
\end{frame}

\begin{frame}{Data Background: Cognitive Decline in Older Adults (cont.)}
	\begin{itemize}
		\item Older adults (75+) are the age group most likely to visit general practitioners for memory and concentration problems.

		\item In the Netherlands, GP visits related to memory and concentration problems increased by 24\% in 2023 compared with 2020\cite{rivm2023}.

		\item Across Europe, cognitive decline is associated with increased dependency on caregivers, creating challenges for independent living and healthcare systems\cite{formanek2019}.
	\end{itemize}
\end{frame}
